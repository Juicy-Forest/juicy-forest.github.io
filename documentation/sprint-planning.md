# Sprint Planning

## Overview

An overview of our sprint plants for this project

## sprint 1 (17/11/2025 - 01/12/2025):
### Start of week demo goal
Get feedback on the initial real code version of the project

### General goals:
* Build the initial skeleton for the front/backend
* Implement the initial routes on the frontend and services on the backend

### Meetings on: 
* Mondays,
* Wednesdays,
* Fridays,
* Additional extra meetings if needed

Meetings will be short, to keep track of the progress everyone has been making + to ask questions

### Related system requirements:
*     TIMO - The dashboard shall display an overview of the garden split by sectors and each sector should give essential information about itself. 

*     TIMO - The dashboard should display general info about the garden (such as temperature, humidity) 

*     ALEX - The map shall provide an overview of the entire garden with a summary of plants planted in each area 

*     GUILLERMO - The application should suggest weekly tasks for the users to complete, and must refresh every week. 

*     ALEX - The map shall allow users to manually add and remove plants to it 

*     GABRIEL - The application shall have a chat interface that allows all users to converse with each other as well as a bot that can answer questions and suggests tasks, which users can then further assign to one another. 

*     GUILLERMO - The application shall allow users to mark alert tasks as complete 

*     SAM - The application shall let users view a categorized inventory for the garden 

*     SAM - The application shall let users manage items in the inventory (add, delete, edit, view) 

*     GUILLERMO - The application shall let users add weekly tasks to each section 

*     GUILLERMO - The application shall provide users an overview of all weekly tasks per section

*     MAIK - The system shall allow the creation/register of a account 

*     MAIK - The system shall allow all users to create, manage and join multiple food gardens
